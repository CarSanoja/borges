DESCRIPTION
What if one defensible analysis choice changed your decision?

Borges stress-tests a data conclusion by exploring alternative analyses in real sandboxes. It shows which paths agree, which choice changes the answer, and how to reproduce the result.

This demo replays a recorded live run of NVIDIA Nemotron on Nebius Token Factory, executed with Token Factory Sandboxes (ConTree). In a synthetic checkout experiment with a planted data problem, excluding internal test sessions changes the estimated lift from +0.85 to -0.15 percentage points, reversing the decision from SHIP to DON'T SHIP.

Explore the analysis paths, inspect the code and sandbox checkpoints, and reproduce the result from the open-source repository.
